# Custom subagent definitions (optional)

This folder is left empty intentionally. The subagent workflow for this project is described in
the root `CLAUDE.md` ("Subagent workflow" section) — backend/frontend/test work is launched via
Claude Code's Task tool with contract-bound prompts, rather than predefined agent config files.

If Claude Code's custom subagent definition format (project-level agent `.md` files with
frontmatter, etc.) would help formalize the backend/frontend/test-reviewer roles described in
`CLAUDE.md`, that can be added here later — check current Claude Code documentation for the
exact expected format before adding files, since this is a fast-moving feature area.
